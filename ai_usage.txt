2. LANGUAGE DESIGN

Prompt / request:
I discussed ideas for creating a custom language. I proposed using "meow" as the assignment operator and different cat emojis as data types.

The final syntax decisions were made during the conversation.

Final language design:

🐱 = i32
🐈 = i64
😺 = bool

meow = assignment (=)
meowmeow = equality comparison (==)
woem = inequality comparison (!=)

Normal keywords were kept for:
var
let
if
else
true
false

The language does not use semicolons and supports negative integer literals.

6. LEXER DEBUGGING

Problem encountered:
The lexer produced:

compilation error: line 1:1: unexpected character

even though the first input byte was "v".

Prompt / debugging process:
I provided the lexer output and debug output to ChatGPT.

AI contribution:
ChatGPT suggested printing the current byte and checking is_letter(). The debug output showed:

BYTE: 118 v
IS LETTER: True

ChatGPT identified that lex_word() was probably being called without returning its result.

The problematic structure was effectively:

if self.is_letter(byte):
    self.lex_word()

It needed to be:

if self.is_letter(byte):
    return self.lex_word()

What I changed / did myself:
I applied the fix and reran the lexer. After the fix, tokenization worked correctly.
